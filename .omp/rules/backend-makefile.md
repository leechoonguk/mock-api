# Makefile Usage Rules


## Self-Documenting Targets

Every target carries a `## <description>` on its header line. `make help` greps
those descriptions, so a target without one exists but cannot be found - and an
undiscoverable target is re-invented as a raw command. `check-makefiles`
enforces it on the root, backend and frontend Makefiles.

## Makefile Targets

| Target | Command | Purpose |
|---|---|---|
| `make help` | `grep -E 'target:.*?## .*'` | Show this help |
| `make install` | `uv sync` | Install Python dependencies (runtime + `dev` group) into `.venv` |
| `make dev` | `ENV=local BACKEND_PORT=… ./scripts/start.sh` | `mkdir -p data` + `alembic upgrade head` + `alembic check` + uvicorn on `127.0.0.1:$(BACKEND_PORT)` (from the root `.env`, default 47821) with reload, in the background; log in `/tmp/mock-api-backend.log`. `ENV=local` is set by the target, so an exported `ENV=production` cannot change what the local target runs |
| `make down` | kill the listener on `$(BACKEND_PORT)` | Stop the backend started by `dev` (the same port) |
| `make clean` | `rm -rf .coverage .pytest_cache .ruff_cache __pycache__` | Remove test, lint, coverage, and Python caches |
| `make migrate` | `alembic upgrade head` | Apply pending migrations to the SQLite file in `backend/data/` |
| `make migrate-down` | `alembic downgrade -1` | Roll back the most recent migration |
| `make migrate-gen` | `alembic revision --autogenerate -m "$(m)"` | Auto-generate a migration from model changes (integer revision ids, `render_as_batch`) |
| `make migrate-check` | `alembic upgrade head` + `alembic check` on a temporary file database | Prove the migrations build the schema the models declare — no diff left for autogenerate |
| `make verify` | `lint + typecheck + test + migrate-check` | Full quality gate (fail-fast) |
| `make test` | `pytest -q -n auto` | Run tests (100% coverage gate; xdist workers) |
| `make test-fast` | `pytest -q --no-cov $(t)` | Tests without the coverage gate; `t="tests/..."` scopes to one file. Stays serial — worker startup outweighs the win on a single file |
| `make fix` | `ruff check --fix` + `ruff format` (app tests — alembic 제외) | Auto-fix lint findings and formatting; migrations are immutable artifacts |
| `make lint` | `ruff check app alembic tests` | Lint Python code (incl. tests) |
| `make typecheck` | `pyright` | Type-check Python code (incl. tests) |

## Usage Conventions

1. **All targets run from `backend/`.** The root delegates with `$(MAKE) -C backend`.
   Every tool runs as `.venv/bin/<tool>`, never a globally installed one.
2. **Verify before commit.** `make verify` (lint + typecheck + test + migrate-check) must pass.
3. **Roll back before re-migrating.** If a migration is broken: `make migrate-down`, fix, `make migrate`.
4. **`migrate-gen` requires `m=` message.** `make migrate-gen m="add foo column"`.
   A revision file is generated, never written by hand.
5. **Run `make migrate` after `migrate-gen`.** An autogenerated migration must be applied.
6. **Run `make migrate-down && make migrate`** after applying a new migration to verify reversibility.
7. **Stop the backend with `make down`.** Use before restarting to avoid port conflicts.
